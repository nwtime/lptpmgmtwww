# Compatibility with LinuxPTP

In addition to IEEE 1588-2019, `libptpmgmt` implements LinuxPTP specific management TLVs.  

The following table specifies the `libptpmgmt` version that supports each LinuxPTP version.  

Note that libptpmgmt version 1.3 supports `AUTHENTICATION TLV`.
<br>

|libptpmgmt|LinuxPTP|
|----------|--------|
|1.0       |4.0     |
|1.1       |4.1     |
|1.2       |4.2     |
|1.3       |4.3     |
